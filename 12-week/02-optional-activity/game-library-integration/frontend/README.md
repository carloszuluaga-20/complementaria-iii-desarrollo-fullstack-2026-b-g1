# Game Library — React (Semana 12)

Frontend de la Biblioteca de Videojuegos, conectado a la API de Spring Boot JWT de la carpeta `../backend`.

Instrucciones completas, puertos, pruebas y pasos de verificación en `../README.md`.

```powershell
npm ci
npm run dev -- --port 5173 --strictPort
```

Interfaz con login, registro, sesión JWT, lista de juegos, CRUD y manejo de carga/error.
